**Source:** `8a_DB_v2.pptx`.

## Video prompt

```text
Create an 8–10 minute exam-preparation video using only Presentation 8a.

Explain the roles of a MySQL server, SQL, Apache, and phpMyAdmin, and show how
they fit together in the web-server/database setup described by the slides.
Walk through the Apache installation and access material, then explain the
SQL exercises and the Python/database example at a conceptual level. Cover
the Dynamic DNS/web-server section as a way of reaching a changing home
network address, but do not claim that it makes a server secure or publicly
available without the prerequisites shown.

Clearly distinguish database engine, query language, administration tool,
and web server. Use a simple request/data flow and explain what each layer
does. Do not invent SQL syntax, credentials, network settings, or exposure
steps not present in the slides. End with a glossary and a troubleshooting
checklist for separating web-server, database, and query problems.

Cite the source slide/section for claims and identify potentially outdated
installation details.
```
