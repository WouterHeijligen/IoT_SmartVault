# Presentation 2b — Bash, Python, and working on the Pi

**Source:** `2b_Bash_Python_HelloWorld_v2.pptx`.

## Video prompt

```text
Create a 10–12 minute exam-preparation video using only Presentation 2b.

Explain the Linux/Bash skills needed to work on a Raspberry Pi: navigating
files and directories, understanding common directories, checking permissions,
network/IP commands, monitoring the system, installing packages, changing
host name or password, and shutting down safely. Then explain the ways shown
for writing/running Python remotely or headlessly: transferring files over
SSH, synchronizing with VS Code, using remote development tools, and the
alternatives in the slides. Close with backup and restore approaches, including
WinSCP, Git, and USB storage.

Teach the purpose and mental model for each workflow, not just a list of
commands. Contrast manual upload, synchronization, and editing remotely.
Highlight the safety and reliability practices implied by the material:
verify the target host, understand where files are stored, protect credentials,
and keep backups. Do not invent command flags or claim one editor is required.
Finish with a compact command/workflow map and common mistakes to avoid.

Cite the presentation and slide/section for important details. If instructions
are platform-specific or appear version-dependent, say so.
```

## Extensive quiz prompt

Use 8 command-purpose or terminology questions, 8 workflow-order questions,
8 short explanations, 15 troubleshooting scenarios, and 6

from the methods actually shown in the slides. Do not require memorizing
undocumented syntax.

Present the full question set first, followed by a separate answer key. Give
reasoning, cite the source slide/section for every answer, and distinguish
commands shown verbatim from general interpretation. Include at least three

interactive quiz one question at a time; wait for my response before revealing
the answer and track the topics I miss.
