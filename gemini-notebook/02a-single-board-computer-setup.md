# Presentation 2a — SBC and Raspberry Pi setup

**Source:** `2a_SBC_RPi_GettingStarted_v2.pptx`.

## Video prompt

```text
Create an 8–12 minute study video using only Presentation 2a.

Teach what a single-board computer (SBC) is, why it is useful in an IoT
solution, and what considerations matter when choosing one. Compare the
Raspberry Pi board options shown in the slides at a high level. Then explain
the Raspberry Pi bring-up workflow: choose and write an OS image, power the
board, establish network access, find its IP address, connect remotely with
SSH, and personalize the setup. Explain the purpose of host name, time zone,
default-password changes, Wi-Fi setup, and remote access tools such as
Raspberry Pi Connect.

Organize the video as a practical sequence, explaining what each step enables
and how to diagnose the connection problems covered in the slides. Clearly
separate general concepts from platform-specific instructions that may change
with software versions. End with a setup checklist and a short troubleshooting
decision tree.

Use the slides as the authority. Cite the presentation and slide/section for
procedural claims; do not invent commands or assume a particular computer OS
unless the slides say so. Call out any potentially outdated version-specific
instructions.
```

the reasoning and cite the source slide/section. Label OS- or version-specific
details as such. Do not add commands absent from the source. Finish with a
five-question oral-exam round and an interactive one-question-at-a-time mode
