Raspberry Pi setup

The application targets a Raspberry Pi with GPIO access, SPI, and I2C. It cannot run unchanged on a regular Windows laptop. Check the hardware notes before connecting components.

1. Prepare the Pi

Use Raspberry Pi OS with Python 3, Git, and Python virtual environment support. Enable SPI and I2C using sudo raspi-config under Interface Options; follow any restart instructions it gives.

2. Install the application

Run these commands in a terminal on the Raspberry Pi:

git clone https://github.com/WouterHeijligen/IoT_SmartVault.git
cd IoT_SmartVault
python3 -m venv env --system-site-packages
source env/bin/activate
python -m pip install -r requirements.txt

Do not add the local env/ directory to Git. Hardware-specific dependencies may also require OS packages appropriate to your Pi and OS version.

3. Configure ThingSpeak

Create a local .env file in the repository root using your own ThingSpeak MQTT device credentials and channel ID:

THINGSPEAK_MQTT_CLIENT_ID=your_client_id
THINGSPEAK_MQTT_USERNAME=your_username
THINGSPEAK_MQTT_PASSWORD=your_password
THINGSPEAK_CHANNEL_ID=your_channel_id

The file is ignored by Git. Never put real credentials into these pages or GitHub Actions. The static documentation needs no ThingSpeak secrets.

The MQTT client targets mqtt3.thingspeak.com:1883, publishing to channels/<channel_id>/publish. It maps field1 to light in lux and field2 to temperature in degrees Celsius. The potentiometer is not published.

Current limitation: main.py does not call mqtt.connect() before publishing. Cloud delivery is not complete in this application flow. The configured MQTT transport is unencrypted; do not treat this prototype as a secure deployment.

4. Run the prototype

source env/bin/activate
python3 main.py

Startup initializes the hardware immediately, including relay and stepper GPIO outputs. Only run with reviewed wiring and a safe mechanical setup. Press the button to take a measurement and trigger the RGB test sequence. Press Ctrl+C to stop; use deactivate to leave the environment.

Reading the potentiometer

The current display shows the raw AnalogIn.value result. Adafruit's API exposes a 16-bit-scaled value even though the MCP3008 is a 10-bit ADC. The existing raw_to_digit() helper expects a 10-bit input and is not called by the main flow. A complete 0-9 code entry interface still needs integration.
